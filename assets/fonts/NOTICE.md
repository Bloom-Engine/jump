# Bundled fonts

`bloom_ja.ttf`, `bloom_ko.ttf`, `bloom_zh.ttf`, `bloom_th.ttf` are **subsets** of
Google's Noto Sans fonts (Noto Sans JP / KR / SC / Thai), containing only the
glyphs Bloom Jump renders, for Japanese, Korean, Simplified Chinese and Thai.

Licensed under the SIL Open Font License 1.1 — see `OFL.txt`.
Regenerate with `tools/build-fonts.py`.
